# 项目约束

## 产品边界

- 本仓库是纯确定性工具库，供外部大模型智能体调用；仓库内不存在发起模型请求的代码。决策由调用方模型承担，本库承担每一步的正确性：参数校验、后置条件、脱敏、非幂等防重放和采集完整性门全部由固定代码执行。
- 第一阶段只覆盖浏览器自动化，不实现窗口自动化驱动，但核心协议不得依赖 DOM 专有概念：页面和窗口统一视为"自动化表面"，DOM 元素和窗口控件统一视为"目标区域"。
- 网络能力对标专业抓包工具的可用性，但只作用于本项目受管的浏览器：完整流量检查（全资源类型的请求/响应头、时序分解、发起方、TLS 证书详情、WebSocket 帧、SSE 消息、按需正文）、HAR 导出、会话内请求重放与编辑重发、任务级 Fetch 路由，以及面向业务落库的结构化采集。不得凭空发起网络访问，也不得代理或劫持受管浏览器以外的流量。
- 请求重放复用当前浏览器会话与凭据，由固定 `fetch` 模板在页面上下文发起；目标必须落在任务允许 origin 内，按非幂等动作处理，失败不自动重试。
- 批量订单、列表和明细必须采用"调用方模型提交受控规格、固定代码批量采集"的分工；原始记录只写入权限收紧（0600）的结果文件，模型视图只接收计数、页数、完整性证据、失败原因和产物引用，不逐条接收业务数据。
- 要求全部数据时，只有代码证明"声明总数与去重数闭合""声明总页数全部覆盖"或"稳定验证分页终点"至少一项，且零失败页、JSON/CSV 双产物齐备，才允许判定完整；单页或单个网络响应默认是部分结果。
- 尚无确定性遍历器的分页形态必须如实返回未完成，不得降级成只导出当前页；DOM 分页动作选择器不得混用。
- 采集程序库只收录经存储前验证门（重进入口 + 结构探针）晋升的成功规格；重放失配必须降权回退并返回明确原因，任务输入值禁止固化进程序。
- 抓取合规默认咨询、显式强制：robots.txt 判定永远可查（`check_crawl_policy`），装配时打开 `respect_robots` 后 `navigate`/`open_tab` 才按判定硬拦并按主机限速；生效间隔取站点声明与调用方配置的较大者，robots 状态未知时遵守模式下不放行。
- 本库不做整站爬取编排、不调模型做 schema 抽取、不管理调用方的会话生命周期；这些属于调用方职责，文档如实写明而不是悄悄承接。

## 工程约束

- Python 3.11+，异步内核，完整类型标注；运行依赖只有 `aiohttp`，新增运行依赖需要明确决策并记录理由。
- 领域协议与 CDP 传输、SQLite 实现隔离。
- 浏览器运行时必须由本项目直接基于 CDP 实现，禁止依赖 Playwright、Selenium 或 DrissionPage，这些项目也不能成为传递依赖。
- 注释、日志、错误信息和维护记录使用中文；标识符遵循 Python 通用英文命名习惯。
- 单个源文件不超过 1500 行，优先按职责拆分。
- 不维护两套完整同步/异步内核，不自研 HTTP 客户端、HTML 解析器或全量 CDP 包装。
- 外部依赖需要说明用途；第三方设计参考需要记录来源与许可证。

## 性能与有界性约束

- 复用浏览器进程，使用 CDP BrowserContext 按项目、租户、站点和账号隔离会话；不得接管用户日常浏览器默认 profile。
- 一切进入模型视图的内容都有界并显式标注截断：观察候选默认截断到 24 个（页面真实总数另报）、正文 Markdown 默认 40000 字符（页面真实总长另报）、流量正文受单体上限与全局字节预算双重约束。
- 超过内存上限的大响应落 0600 私有文件而不是丢弃，`read_network_body` 返回路径。
- URL 记忆与采集程序库的数据库读写经共享后台运行时执行，不阻塞工具调用主路径。

## 状态约束

- 只有通过测试或可重复演示的功能才标记"已实现"；已写接口但没有端到端验证的功能标记"部分实现"。
- 每次文件改动更新 `docs/change_maintenance/CHANGELOG.md`；每次功能变化更新 `docs/PROJECT_STATUS.md`；需求变化同时更新需求基线。
- 文档中的工具数量等口径必须与代码实测一致；能被契约测试锁定的口径优先锁定（`tests/test_toolkit_skill_contract.py` 是范例）。
